# Ordduellen ⚔️

Ett ordspel där elever duellerar med glosor (svenska ⇄ engelska). Skjut ord mot motståndaren – försvara dig genom att skriva översättningen innan ordet träffar.

**Spela:** https://joshuamrumack-collab.github.io/ordduellen/

- Mot bot, interaktiv guide, eller online: duell, lagstrid och co-op mot bot
- Egna ordlistor (klistra in från Excel/Kalkylark), färdiga kategorier
- Fungerar inbäddad på Google Sites (Infoga → Bädda in → Via webbadress)

Allt finns i `index.html`. Onlinespelet använder Firebase (Firestore + anonym inloggning).
