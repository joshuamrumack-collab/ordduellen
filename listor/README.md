# 📁 Klassens ordlistor

Varje textfil i den här mappen blir en ordlista som syns under **📁 Klassens listor** i spelet.

## Lägga till en lista (direkt på github.com)

1. Klicka **Add file → Create new file** här i mappen `listor`.
2. Döp filen till t.ex. `vecka12.txt` (små bokstäver, inga mellanslag).
3. Skriv namnet på första raden med `#` framför, och sedan ett ordpar per rad:

```
# Vecka 12 – djur
katt = cat
hund = dog
höst = autumn/fall
```

4. Klicka **Commit changes**.

Efter någon minut finns listan i spelet. Listan får också en egen länk som du kan dela:

`https://joshuamrumack-collab.github.io/ordduellen/?lista=vecka12`

**Tips:** Med `/` godkänns flera svar (`höst = autumn/fall`). Du kan också använda `;`, tab eller ` - ` mellan orden, och klistra in direkt från Excel eller Google Kalkylark.

`index.json` uppdateras automatiskt – du behöver inte röra den.
